# Plateforme d’aménagement paysager — Devis, Rendez‑vous, Paie

Plateforme PWA pour une entreprise d’aménagement paysager: calcul de devis avec liste de prix manuelle, prise de rendez‑vous et calendrier (9h‑17h L‑V, 60 min), gestion des retours d’appels/courriels, planning d’employés, préparation de paie. Stack moderne (React + Node + PostgreSQL).
